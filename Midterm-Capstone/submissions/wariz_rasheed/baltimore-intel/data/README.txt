This folder holds the three input CSV files (one per dataset):

  NIBRS Group A Crime Data          file name contains "NIBRS"
  311 Customer Service Requests     file name contains "311"
  Liquor Licenses                   file name contains "icense" (e.g. Licenses.csv)

If the files are zipped, unzip them here so they are plain .csv files.
Source: https://data.baltimorecity.gov/ (Export > CSV).
Keep exactly one file per dataset in this folder.
